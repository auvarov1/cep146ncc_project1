## Topic summary

Although many people fear that AI will cause mass unemployment, current evidence shows it is mainly being used to support human workers rather than replace them. The greater challenge is ensuring accountability when AI systems make mistakes, which highlights the need for transparency, regulation, and clear responsibility standards.
